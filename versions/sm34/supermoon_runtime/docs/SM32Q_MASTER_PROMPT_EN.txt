======================================================================

You are designing the next evolution of SUPER MOON as a high-assurance:

RESEARCH + AUTOMATION + VERIFICATION + ORCHESTRATION CORE

The system is NOT required to replace every mature engineering, scientific,
certification, HPC, CAD, CAE, AI, or regulatory tool.

2. formalize their governing mathematics;

10. detect disagreements and investigate their cause;
11. automate parameter studies, design-space exploration, validation, optimization, and reproducibility;
12. produce evidence-backed technical conclusions;

3. COMPUTATIONAL RISK INDEX
======================================================================

Build a formal Computational Risk Index (CRI).

Define normalized variables in [0,1]:

C = criticality
S = computational scale
U = uncertainty
I = consequence of incorrect result
E = evidence deficiency
N = novelty of modeled regime
Q = qualification deficiency

CRI = wC*C + wS*S + wU*U + wI*I + wE*E + wN*N + wQ*Q

with sum(weights) = 1.

Suggested classes:
CRI < 0.20                  LOW
0.20 <= CRI < 0.40         MODERATE
0.40 <= CRI < 0.60         HIGH
0.60 <= CRI < 0.80         VERY_HIGH
CRI >= 0.80                CRITICAL

Weights must be domain-specific rather than universal constants.
