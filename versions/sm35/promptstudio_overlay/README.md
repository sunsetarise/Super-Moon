# Prompt Studio SM35 overlay

This overlay preserves the complete supplied SM34 Prompt Studio archive and adds
an SM35 runtime bridge plus `/api/sm35/overview`. The installer copies only new
`supermoon35` files and inserts two idempotent integration lines; it does not
remove or rename any SM31/SM32/SM34 code, endpoint, asset, knowledge base, or
evidence file. The displayed state remains `BLOCKED_PENDING_REAL_EXECUTION`.
