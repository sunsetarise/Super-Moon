# Security Policy

Report suspected vulnerabilities privately through the repository's GitHub
Security Advisories after the repository owner enables them. Do not include
credentials, export-controlled material, proprietary solver data, or sensitive
infrastructure details in public issues.

Supported source line: Super Moon 36 and additive compatibility fixes for
SM34/SM35. Historical evidence is immutable unless a corrected record retains
the original and documents the supersession.

Physical runners must use explicit command allowlists, isolated workspaces,
least-privilege scheduler accounts, pinned dependencies, and content-addressed
evidence. Untrusted receipts must never be treated as qualification evidence.
