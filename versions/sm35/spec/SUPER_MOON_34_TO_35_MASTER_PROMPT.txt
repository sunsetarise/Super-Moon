SECTION 18 — PERFORMANCE AND STATISTICAL ENGINEERING
================================================================================

18.1 Correctness gates precede speed gates.

18.2 Define work units before benchmarking.

18.3 Record warm-up policy and raw repeated samples.

18.4 Use synchronized timing for asynchronous devices and distributed runs.

18.5 Report median, MAD, confidence interval, coefficient of variation, and
     outlier policy.

18.6 Normalize performance by hardware and workload when comparing machines.

18.7 Record compiler flags, thread affinity, frequency/power state, memory mode,
     and background load where available.

18.8 Calculate:

    speedup S_p = T_1 / T_p
    strong efficiency E_s = S_p / p
    weak efficiency E_w = T_1 / T_p for constant local work
    Karp-Flatt e = (1/S_p - 1/p) / (1 - 1/p)
    arithmetic intensity = FLOPs / bytes transferred
    roofline bound = min(peak FLOPs, intensity * bandwidth)
    GPU speedup = equal-work CPU time / synchronized GPU time
    checkpoint overhead = (T_with - T_without) / T_without
    cost-to-solution = node-hours + GPU-hours + storage + transfer cost

18.9 Preserve performance regressions even when correctness passes.

18.10 Do not compare unequal work, unequal tolerances, or unequal output fidelity.
