🔍 Verification vs Validation
SUPER MOON keeps these separate.
Verification
> **Are we solving the equations correctly?**
Examples:
residual recomputation;
analytical solutions;
manufactured solutions;
convergence order;
mutation tests;
independent implementations.
Validation
> **Are these equations/models sufficiently representative of the real system for the intended decision?**
Examples:
experimental comparison;
external solver comparison;
validated materials;
real physical data;
defined applicability domain.

🧷 Reassembling split release artifacts
If a large `.txt.gz` release is distributed as ordered chunks:
```text
release.txt.gz.001
release.txt.gz.002
release.txt.gz.003
...
```
Linux / macOS
```bash
cat release.txt.gz.001 \
    release.txt.gz.002 \
    release.txt.gz.003 \
    release.txt.gz.004 \
    release.txt.gz.005 \
    > release.txt.gz

gzip -t release.txt.gz
sha256sum release.txt.gz
```
Windows CMD
```bat
copy /b release.txt.gz.001+release.txt.gz.002+release.txt.gz.003+release.txt.gz.004+release.txt.gz.005 release.txt.gz
```
PowerShell
```powershell
$out = [System.IO.File]::Create("release.txt.gz")
try {
    1..5 | ForEach-Object {
        $part = "release.txt.gz.{0:D3}" -f $_
        $bytes = [System.IO.File]::ReadAllBytes($part)
        $out.Write($bytes, 0, $bytes.Length)
    }
}
finally {
    $out.Close()
}
```
Always verify the published SHA-256 after reconstruction.
